# 🩺 基礎看護技術 手順確認アプリ

基礎看護技術の手順・必要物品・根拠（留意点）をブラウザ上で手軽に確認・暗記学習し、学習回数や自分用の注目箇所まで記録・可視化できる Streamlit 製の教育・演習サポートアプリです。

## 主な機能

* **2種類のマーカー機能（重要ポイント＆自分用チェック）**
  * **薄い黄色マーカー**：手技の中で特に注意すべき重要なポイントを最初から強調表示します。
  * **淡い水色マーカー**：各手順の左にあるチェックボックスを入れると、その手順の文章に水色マーカーが引かれます（黄色マーカーはそのまま残るため、色分けして確認できます）。
* **🙈 暗記モード（穴埋めテスト機能）**：サイドバーのトグルスイッチをONにすると、黄色マーカー部分の文字が隠れて穴埋め状態になります。隠れた箇所にマウスカーソルを合わせる（スマホ・タブレットではタップする）と、個別に答えを確認できます。
* **折りたたみ式カテゴリー＆あいうえお順ナビゲーション**：サイドバーの技術一覧はカテゴリーごとに開閉（折りたたみ）でき、各カテゴリー内は読み仮名に基づく**あいうえお順**で自動整列します。
* **キーワード検索＆絞り込みクリア**：手技名・目的・手順・根拠のキーワード検索やカテゴリー絞り込みに対応し、「🧹 検索・絞り込みをクリア」ボタンでワンクリック解除できます。
* **👀 確認回数の記録と自動保存**：統一された操作枠から **「✅ 確認完了（+1回）」「↩️ -1回」「🗑️ クリア（0回）」** で回数を管理できます。記録はブラウザのURLパラメータ（`?c=...`）に自動保存されるため、ページを再読み込みしたりブックマークから開き直したりしても記録が保持されます（JSON形式での保存・復元にも対応）。
* **📊 確認回数グラフ表示**：「📊 確認回数グラフ」タブから、手技別・カテゴリー別の確認回数を縦軸位置の揃った横棒グラフで一覧比較でき、未確認の手技をひと目で把握できます（スクロール時の誤ズーム防止済み）。

## 収録されている基礎看護技術（全15手技・カテゴリー別）

* **栄養援助**
  * 経鼻胃管からの経管栄養法（注入の手順）
* **活動・休息援助**
  * 仰臥位から側臥位への体位変換
* **感染予防**
  * 衛生的手洗い（流水と石けん）
* **環境整備**
  * ベッドメーキング（臥床患者がいない場合）
* **呼吸・循環援助**
  * 口腔・鼻腔内吸引（一時的吸引）
  * 酸素吸入療法（鼻カニューレ・酸素マスク）
* **診療の補助**
  * 静脈血採血（真空採血管ホルダー法）
* **清潔・衣生活援助**
  * 口腔ケア（誤嚥予防を意識したブラッシング）
  * 全身清拭（ベッド上での清拭）
* **排泄援助**
  * 一時的導尿（女性患者）
* **バイタルサイン**
  * 血圧測定（上腕・聴診法）
* **無菌操作**
  * 滅菌手袋の装着（オープン法）
* **与薬技術**
  * 筋肉内注射（中殿筋部位）
  * 静脈内注射（ワンショット静注）
  * 皮下注射（上腕伸側など）

## ローカル環境での実行方法

1. リポジトリをクローンまたはダウンロードします。
2. 必要なライブラリをインストールします（`requirements.txt` には `streamlit` を記載）。

```bash
pip install -r requirements.txt
```

3. 以下のコマンドでアプリを起動します。

```bash
streamlit run app.py
```

## Streamlit Community Cloud へのデプロイ方法

1. `app.py`、`requirements.txt`、`README.md` を GitHub のリポジトリにプッシュします。
2. [Streamlit Community Cloud](https://share.streamlit.io/) にログインし、**「Create app」** をクリックします。
3. 対象のリポジトリ・ブランチ（`main`）・メインファイル（`app.py`）を選択し、**「Deploy」** をクリックすると公開URLが発行されます。

## 手技データの追加・編集方法

`app.py` 内の `RAW_NURSING_PROCEDURES` リストに、以下の形式で辞書データを追加してください。`category_reading` と `reading` にひらがなの読みを入れておくと、自動的にカテゴリー別・あいうえお順で並びます。

```python
{
    "id": "unique_id",
    "category": "カテゴリー名",
    "category_reading": "かてごりーめいのよみ",
    "title": "看護技術のタイトル",
    "reading": "かんごぎじゅつのよみ",
    "purpose": "手技の目的",
    "items": ["必要物品1", "必要物品2"],
    "steps": [
        {
            "step": "1. ステップ名",
            "action": "具体的な手順（<span class='marker'>重要なポイント</span>を強調）",
            "rationale": "根拠・留意点",
        },
    ],
}
```
