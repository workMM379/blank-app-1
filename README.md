# 🩺 基礎看護技術 手順確認アプリ

基礎看護技術の手順・必要物品・根拠（留意点）をブラウザ上で手軽に確認・暗記学習し、学習回数まで記録・可視化できる Streamlit 製の教育・演習サポートアプリです。

## 主な機能

* **重要ポイントのマーカー表示**
  ：手技の中で特に注意すべき箇所を薄い黄色マーカー（蛍光ペン風）で強調表示します。
* **暗記モード（穴埋めテスト機能）**
：サイドバーのトグルスイッチをONにすると、黄色マーカー部分の文字が隠れて穴埋め状態になります。隠れた箇所にマウスカーソルを合わせる（スマホ・タブレットではタップする）と、個別に答えを確認できます。
* **👀 確認回数の記録と自動保存**
  ：各手技の「✅ 確認完了（+1回）」ボタンを押すと確認回数がカウントされます。記録はブラウザのURLパラメータに自動保存されるため、**ページを再読み込みしたりブックマークから開き直したりしても記録が保持**されます。サイドバーから JSON ファイルとしての保存・復元も可能です。
* **📊 確認回数グラフ表示**：「📊 確認回数グラフ」タブから、手技別およびカテゴリー別の確認回数を横棒グラフで一覧比較でき、復習が不足している技術をひと目で把握できます。
* **キーワード検索＆カテゴリー絞り込み**
  ：手技名だけでなく、目的・手順・根拠に含まれるキーワード（例：「逆血」「クラーク」「吸引圧」など）やカテゴリーから該当する技術を素早く検索できます。
* **演習用チェックリスト**
  ：各ステップにチェックボックスを備えており、手技の確認や実技演習時の進捗チェックに活用できます。

## 収録されている基礎看護技術（全13手技）

1. **【感染予防】** 衛生的手洗い（流水と石けん）
2. **【バイタルサイン】** 血圧測定（上腕・聴診法）
3. **【無菌操作】** 滅菌手袋の装着（オープン法）
4. **【与薬技術】** 筋肉内注射（中殿筋部位）
5. **【活動・休息援助】** 仰臥位から側臥位への体位変換
6. **【診療の補助】** 静脈血採血（真空採血管ホルダー法）
7. **【排泄援助】** 一時的導尿（女性患者）
8. **【栄養援助】** 経鼻胃管からの経管栄養法（注入の手順）
9. **【清潔・衣生活援助】** 全身清拭（ベッド上での清拭）
10. **【呼吸・循環援助】** 口腔・鼻腔内吸引（一時的吸引）
11. **【呼吸・循環援助】** 酸素吸入療法（鼻カニューレ・酸素マスク）
12. **【清潔・衣生活援助】** 口腔ケア（誤嚥予防を意識したブラッシング）
13. **【環境整備】** ベッドメーキング（臥床患者がいない場合）

## 実行方法

以下のコマンドでアプリを起動します。

```bash
streamlit run app.py
```


## 手技データの追加・編集方法

`app.py` 内の `NURSING_PROCEDURES` リストに、以下の形式で辞書データを追加してください。文章中で黄色マーカー（および暗記モードの穴埋め対象）にしたい箇所は `<span class='marker'>〜</span>` で囲みます。

```python
{
    "id": "unique_id",
    "category": "カテゴリー名",
    "title": "看護技術のタイトル",
    "purpose": "手技の目的",
    "items": ["必要物品1", "必要物品2"],
    "steps": [
        {
            "step": "1. ステップ名",
            "action": "具体的な手順（<span class='marker'>重要なポイント</span>を強調）",
            "rationale": "根拠・留意点",
        },
    ],
}
```
